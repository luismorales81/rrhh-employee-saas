# BRANCHES AND LOCATIONS

Version: 1.0

## Objetivo

Permitir gestionar múltiples sedes.

---

# Entidades

Branch

- Id
- CompanyId
- Name
- Address
- City
- Province
- Country
- IsActive

---

# Empleados

Cada empleado puede pertenecer a:

- Una sucursal principal
- Múltiples ubicaciones secundarias

---

# Casos de Uso

Casa Central

Sucursal Córdoba

Sucursal Tucumán

Depósito Norte

---

# Comunicaciones

Enviar a:

- Toda la empresa
- Una sucursal
- Varias sucursales

---

# Reportes

Filtrar por:

- Sucursal
- Ciudad
- Provincia

---

# Vacaciones

Permitir calendarios diferentes por sucursal.

---

# Feriados

Cada sucursal puede tener:

- Calendario propio
- Días especiales

---

# Escalabilidad

Preparar soporte para:

- Empresas multinacionales
- Diferentes zonas horarias
