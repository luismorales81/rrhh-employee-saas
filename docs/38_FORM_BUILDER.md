# FORM BUILDER

Version: 1.0

## Objetivo

Permitir que cada empresa cree formularios sin desarrollo.

---

# Casos de Uso

- Solicitudes
- Onboarding
- Offboarding
- Encuestas
- Activos

---

# Tipos de Campo

Texto

Número

Fecha

Checkbox

Radio Button

Lista

Multiselección

Archivo

Firma

---

# Propiedades

- Obligatorio
- Visible
- Editable
- Valor por defecto

---

# Validaciones

- Longitud mínima
- Longitud máxima
- Expresión regular
- Archivo obligatorio

---

# Ejemplo

Solicitud de Vehículo

Campo:
Destino

Campo:
Motivo

Campo:
Fecha

Campo:
Adjunto

---

# Permisos

Cada campo puede definir:

- Quién lo visualiza
- Quién lo modifica

---

# Auditoría

Toda modificación queda registrada.
