## Dashboard

Tarjetas:
- Recibos pendientes
- Vacaciones disponibles
- Solicitudes abiertas
- Documentos pendientes

## Requisitos UX

- Menos de 3 clics por acción frecuente.
- Tiempo de carga inferior a 2 segundos.
- Accesibilidad.

## Firma digital (app móvil)

Canal principal para firmar documentos laborales.

Flujo:
1. Notificación de documento pendiente de firma
2. Visualización del PDF en la app
3. Validación de identidad (sesión activa + segundo factor si está configurado)
4. Firma digital con certificado del empleado o proveedor integrado
5. Confirmación visual y descarga del documento firmado
6. Registro en auditoría

Requisitos UX firma:
- Máximo 3 clics desde la notificación hasta firmar
- Preview del documento antes de firmar
- Estado visible: Pendiente / Firmado / Rechazado / Vencido
- Acceso offline al historial de documentos ya firmados (solo lectura)
