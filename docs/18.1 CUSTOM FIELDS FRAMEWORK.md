# CUSTOM FIELDS FRAMEWORK

## Objetivo

Permitir que cada empresa agregue información propia sin necesidad de desarrollo.

## Entidades soportadas

- Employee
- Request
- Asset
- Document
- Company

---

## Tipos de campo

- Texto
- Número
- Fecha
- Boolean
- Lista
- Multiselección
- Archivo

---

## Ejemplos

Employee

- Talle camisa
- Talle pantalón
- Grupo sanguíneo
- Carnet conducir
- Matrícula

Request

- Centro de costo
- Proyecto

Asset

- IMEI
- Garantía

---

## Reglas

Los campos personalizados:

- son auditables
- pueden ser obligatorios
- pueden tener validaciones
- pueden tener permisos
