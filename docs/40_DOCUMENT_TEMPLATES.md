# DOCUMENT TEMPLATES

Version: 1.0

## Objetivo

Generar documentos automáticamente.

---

# Casos de Uso

- Contratos
- Certificados
- Reglamentos
- Apercibimientos
- Constancias laborales

---

# Variables

Ejemplos:

{{Employee.FirstName}}

{{Employee.LastName}}

{{Employee.DNI}}

{{Employee.HireDate}}

{{Company.Name}}

---

# Plantilla

Formato:

HTML

Futuro:

DOCX

PDF

---

# Generación

Usuario selecciona:

- Plantilla
- Empleado

Sistema genera documento.

---

# Firma

Documento generado puede:

- Requerir lectura
- Requerir firma

---

# Versionado

Toda plantilla debe tener:

- Versión
- Fecha creación
- Estado

---

# Auditoría

Registrar:

- Quién generó
- Cuándo
- Con qué datos
